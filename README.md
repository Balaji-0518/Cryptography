# RSA Encryption/Decryption Web Tool
This is a lightweight, browser-based tool for performing RSA encryption and decryption using JavaScript and the Forge cryptographic library.
It allows users to generate RSA key pairs, encrypt plaintext using the public key, and decrypt ciphertext using the private key—all without sending any data to a server.
# Features :
- Generate RSA key pairs (2048-bit)
- Encrypt messages using RSA-OAEP padding
- Decrypt messages securely in-browser
- Clean, responsive UI built with HTML and CSS
- No backend required—fully client-side
- 
  #  How to Use: 
- Click Generate RSA Keys to create a new public/private key pair.
- Enter plaintext in the Encrypt section and click Encrypt.
- Copy the encrypted output and paste it into the Decrypt section.
- Click Decrypt to reveal the original message.
- 
  # Technologies Used :
- HTML5
- CSS3
- JavaScript (ES6)
